检查范围：

| 操作 | 检查内容 |
| --- | --- |
| 样式选择、标题数 | 过滤保留选择，隐藏标题不参与当前显示列表，避免读取属性时写回错误值 |
| 加载、读取文档样式 | 读取真实样式对象，清理旧映射，包含未使用的自定义段落样式，排除字符样式 |
| 添加、删除 | 名称查重覆盖隐藏样式；添加保留悬挂符号；删除后重建选择及关系列表 |
| 字体、字号、粗体、斜体、下划线、颜色 | 编辑事件、任意有效字号、分数字号保留、Word 布尔值读取、颜色序列化 |
| 对齐、缩进和单位 | 多选占位符不偏移枚举，首行/悬挂/无切换正确，单位转换不强制重置 |
| 行距、段前段后 | 区分固定、最小值和倍数；编辑小数时不插入单位；拒绝无效数值 |
| 预设、导入、导出 | 标题数、格式规则和颜色持久化；兼容旧 XML；无效数据不替换当前编辑内容；预设名称支持下拉、手动输入、空白校验 |
| 样式基准、后续样式 | 刷新选项不改写模型；校验循环基准；实际写入 Word 并报告失败 |
| 应用当前、应用全部 | 实际写入 Word、批量仅写修改字段、保留未改属性、失败不显示成功、支持撤销 |
| 关闭、重复打开、切换文档 | 重复激活保留当前编辑；跨文档应用前要求刷新；底部按钮随窗口尺寸布局 |
| 嵌套窗口 | 使用原生宿主句柄建立所属关系；保存窗口取消、关闭、确定后所属关系不丢失，关闭样式窗口不隐藏或最小化宿主 |

编译后请在 Word 中验收：

1. 点击“样式设置”→“存预设”，下拉选择已有名称或直接输入同名；确定后再次加载该预设，检查样式、颜色和标题数均为新值，且列表中只有一个同名项。内置风格名称同样允许覆盖，建议使用测试账号验收，避免改动个人预设。
2. 输入全空白名称时“确定”不可用；取消、Esc 和右上角关闭均不保存。
3. 分别通过“取消”、Esc、右上角关闭和“确定”退出保存窗口，再通过“关闭”、右上角关闭退出样式窗口，检查 Word 保持前台且不最小化；重复打开保存窗口后再次检查。
4. 对照仅打开并关闭样式窗口，以及多个 Word 文档窗口下的操作，检查焦点回到打开样式设置的文档窗口。

## 多级列表命名预设（2026-10-16）

- 新增“预设风格”“载入”“存预设”“删预设/恢复默认”，内置“默认风格”“多级数字”“中文层级”。首次打开不自动载入，保持原来零级起始状态。
- 下拉切换预设立即载入编辑区；编辑后可点“载入”重新载入同一预设。只有“应用”才写入 Word。
- “存预设”复用可输入名称的保存窗口，支持选已有名称或输入新名称；同名直接覆盖（含内置名称），不重复添加。保存级数、编号属性、起始/重编号规则及每级样式（含隐藏级别样式与颜色）。
- 自定义预设可确认删除；内置预设保存覆盖后显示“恢复默认”，仅删除覆盖版本。删除/恢复保留当前编辑内容，需再次选择预设载入默认值。
